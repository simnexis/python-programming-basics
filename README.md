# 🐍 Python Programming Basics

> **A comprehensive curriculum covering Python fundamentals, procedural problem-solving, structured data collections, error handling, and terminal mini-projects.**

---

## 📌 Repository Overview

This repository provides an organized, hands-on learning roadmap in core Python programming. Focusing on algorithmic thinking, clean coding practices, and core language idioms, it progresses from operators and control structures to data structures, robust exception handling, and functional terminal applications.

---

## 🚀 Terminal Mini-Projects

Located in [mini_projects/](mini_projects/):

| Project | Description | Key Mechanics |
| :--- | :--- | :--- |
| **[Student Management System](mini_projects/student_management.py)** | Interactive console CRUD application managing student records, grade calculations, and GPA reporting. | Dictionaries, lists, input validation, formatted reporting |
| **[Number Analyzer](mini_projects/number_analyzer.py)** | Mathematical analysis tool computing primes, factors, armstrong properties, and statistical distributions. | Algorithmic logic, mathematical functions, modular design |
| **[CLI Calculator](mini_projects/calculator.py)** | Multi-operation terminal calculator supporting arithmetic, exponentiation, and error-guarded division. | Exception handling, loops, clean command loop |

## 🗂️ Curriculum & Repository Structure

`	ext
python-programming-basics/
├── operators/                # Arithmetic, relational, assignment, logical & identity operators
├── conditionals/             # if, if-else, elif ladders & nested conditional blocks
├── loops/                    # for loops, while loops, range generation & nested iteration
├── loop_control_statements/  # break, continue, and pass statements

├── methods/                  # Built-in data structure methods and mutations
├── functions/                # Function definitions, *args, **kwargs, return values & docstrings
├── exception_handling/       # try, except, else, finally blocks and raising ValueError/TypeError
└── mini_projects/            # Interactive command-line applications
`

---

## 🔬 Core Learning Objectives

- **Control Flow**: Writing deterministic branching and defensive input validation.
- **Data Structures**: Selecting appropriate collections (e.g., fast lookups via dict / set vs ordered sequences via list / 	uple).
- **Algorithmic Logic**: Decomposing arithmetic and numeric problems into clean, testable subroutines.
- **Robust Exception Handling**: Preventing runtime crashes using structured 	ry...except...finally blocks.
